🔹 Task 2 – Sensor-Based Simulation
For this task, I created a sensor-based simulation using Tinkercad.

The project uses an Arduino UNO and PIR sensor to detect motion and control an LED. This simulation helped me understand the basics of sensor interfacing, Arduino programming, circuit connections, and automation.

Components & Tools
Arduino UNO
PIR Sensor
LED
Resistor
Tinkercad
Arduino Programming
Embedded C
How It Works
The PIR sensor detects movement and sends the signal to the Arduino UNO. When motion is detected, the Arduino turns the LED ON. When there is no detected movement, the LED remains OFF.
